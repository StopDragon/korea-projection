# Korea Projection

한국 현대·기아 내비(Gen5W 헤드유닛)에서 **무선 카플레이**를 쓸 수 있게 해 주는 NEMESIS 패키지입니다.

한국 내수 펌웨어에서는 HMG-API 무선 모드가 Wi-Fi 핫스팟을 요청해도 순정 핫스팟이 켜지지 않습니다. 이 패키지가 부팅할 때 순정 `hostapd`(핫스팟)와 `dnsmasq`(IP 나눠 주기)를 직접 켜서 아이폰이 무선으로 붙을 수 있게 합니다.

1.5부터는 확인된 차에서 **HMG-API 무선 모드와 그 차의 지도도 자동으로 설치**합니다. HMG-API 앱에서 따로 설정하지 않아도 됩니다.

> ⚠️ 차량 소프트웨어를 바꾸는 일입니다. 모든 책임은 차 주인에게 있습니다. 운행 중에는 조작하지 마세요.

## 지원 차량

| 차종 | 내비 소프트웨어 | 상태 |
|---|---|---|
| 기아 니로 하이브리드 (2020, DE PE) | `DEPEHEV.KOR.0000.V039.001.260902` | ✅ 확인됨 (무선 카플레이, 계기판 길안내, 상태 화면·QR 제보) |
| 현대 쏘나타 하이브리드 (2021, DN8) | `DN822HEV.KOR.0000.V039.001.260902` | 🧪 차 테스트 중 (HMG-API 지도 확인 통과, 무선 카플레이 결과를 기다립니다) |
| 그 밖의 한국 차 | `*.KOR.*` | ⏳ 제보를 기다립니다. 지금은 설치해도 핫스팟을 켜지 않고 대기만 합니다 |

내 차에서 되는지 알려 주시면 지원 목록에 추가합니다. [차량 제보하기](../../issues/new?template=car-report.yml)

지원 목록에 없는 차는 [내 차 제보 가이드](docs/car-report-guide.md)대로 리포트 두 개를 보내 주세요. 그 차의 설정을 만들어 다음 버전에 넣습니다.

## 필요한 것

1. **NEMESIS** 1.16 이상
2. **HMG-API** 1.0.2 이상
3. **Korea Projection** (이 패키지)

나머지는 Korea Projection이 확인된 차에서 자동으로 갖춥니다(1.5 이상).
- **HMG-API 무선 모드**(Wireless CarPlay + Android Auto): 없으면 설치합니다. 차주가 일부러 지우거나 꺼 둔 것은 다시 설치하지 않습니다.
- **그 차의 HMG-API 지도:** 없으면 넣고, 차에 맞는지 확인합니다.
- 설치 뒤 2~3분이면 "무선 카플레이 설정을 마쳤습니다. 차를 껐다 켜 주세요"가 뜹니다.
- 넣는 무선 모드는 HMG-API 공식 모드에 한국 차를 더한 **"한국 차 빌드"**입니다. HMG-API 공식판에 한국 차 지원이 아직 없기 때문입니다([VysseCodes/HMG-API#22](https://github.com/VysseCodes/HMG-API/pull/22)). 공식판이 지원하면 공식 모드로 옮깁니다.
- Korea Projection을 삭제하면, 함께 설치했던 무선 모드도 지웁니다.

`wireless.projection` 패키지는 **필요 없습니다.**
- 이미 설치되어 있다면 그대로 두어도 됩니다.
- 지우면 무선 기능 파일이 함께 지워지는데, Korea Projection 1.2부터는 부팅 때 자동으로 복구합니다. 복구한 뒤 차를 한 번 껐다 켜라는 안내가 뜹니다.

## 설치

처음이시면 **[설치 가이드](docs/install-guide.md)**를 따라 하세요. 포맷부터 아이폰 연결, 잘 안 될 때까지 한 단계씩 적었습니다.

1. USB를 **FAT32**로 포맷합니다(32GB 이하 USB 권장).
2. [릴리스](../../releases/latest)에서 **`korea-projection-버전-usb.zip`**을 받습니다. `NEMESIS.data`는 안에 들어 있으니 만들지 않아도 됩니다.
3. 압축을 풀고, 풀린 폴더 **안에 있는 것**을 USB **맨 위**에 복사합니다.
   ```
   USB
   ├─ NEMESIS.data
   ├─ README.txt
   └─ packages
       └─ korea.projection.zip   ← 이 파일은 압축을 풀지 마세요
   ```
4. 내비 화면이 다 뜬 뒤 USB를 꽂고, 설치할지 물으면 **예**를 누릅니다.
5. USB를 빼고 **2~3분 기다립니다.** "무선 카플레이 설정을 마쳤습니다" 안내가 뜨면, 차를 끄고 문을 열었다 닫은 뒤 다시 켭니다. 아이폰에서 무선 카플레이를 연결합니다.

NEMESIS Manager의 Package Store에서도 설치할 수 있습니다(등록 후).

## 상태 확인과 제보

NEMESIS Manager → My Packages → Korea Projection → **Launch**를 누르세요.

- 내비 화면에 **상태 화면**이 뜹니다.
  - 맨 위에 한 줄 판정이 색으로 나옵니다(초록: 준비됨/연결됨, 노랑: 확인 필요, 빨강: 문제).
  - 왼쪽에는 무선 기능, 핫스팟, DHCP, 카플레이 연결 수 같은 상태표가 나옵니다.
- 오른쪽 **QR을 폰 카메라로 찍으면** 내용이 채워진 [차량 제보](../../issues/new?template=car-report.yml) 양식이 열립니다. 차종과 결과만 고르고 제출하면 됩니다.
- QR과 리포트에는 비밀번호, SSID, 휴대폰 이름, MAC, IP가 들어가지 않습니다. 길이와 예/아니요만 적습니다.
- USB가 꽂혀 있으면 자세한 리포트(`korea-projection-report.md`)도 USB에 저장합니다.
- 지원 목록에 없는 차이거나 준비가 덜 된 차라면, HMG-API Car Report도 **자동으로** USB에 저장합니다(약 1분, "이제 USB를 빼셔도 됩니다"가 뜰 때까지 꽂아 두세요). 두 파일을 [내 차 제보 가이드](docs/car-report-guide.md)대로 첨부해 주세요.

## 알아 두실 점

- 핫스팟이 켜져 있는 동안에는 **내비가 휴대폰 핫스팟(일반 Wi-Fi)에 붙을 수 없습니다.** 한 Wi-Fi 칩이 핫스팟 역할을 하기 때문입니다.
- 계기판 길안내(회전 안내)는 **휴대폰 앱이 회전 정보를 보낼 때만** 나옵니다.
  - 카카오맵: 동작 확인. 다만 회전 정보가 오지 않은 날이 한 번 있어 확인 중입니다.
  - T맵: 앱의 전체 → 연구소 → "카플레이 HUD 연동"을 켜야 합니다.
- 차 설정에서 ADB TCP가 켜져 있으면 HMG-API가 경고를 띄웁니다. 이 패키지는 `192.168.43.x` 대역을 써서 영향이 없었습니다.

## 삭제

NEMESIS Manager → My Packages → Korea Projection → **Uninstall**을 누르면 다음과 같이 정리됩니다.
- 이 패키지가 켠 핫스팟과 DHCP를 멈춥니다.
- 설정 파일, 작업 폴더, 백업을 지웁니다.
- 설치 전에 Wi-Fi가 꺼져 있던 차는 다시 끕니다.
- 삭제가 끝나면 **차를 한 번 껐다 켜 주세요**(문을 열었다 닫기). 일반 Wi-Fi가 원래대로 돌아옵니다.

HMG-API의 무선 기능 파일은 HMG-API 것이므로 지우지 않습니다.

삭제할 때 Wi-Fi를 껐다 켜지 않는 이유가 있습니다. 니로에서 확인해 보니 Wi-Fi를 껐다 켜면 Wi-Fi·블루투스 모듈이 다시 시작되고, 블루투스 카플레이가 재부팅 전까지 되지 않았습니다(1.2까지의 동작).

## 개발

- 패키지 소스: `nemesis-pkg/korea.projection/`, 상태 화면 앱: `nemesis-pkg/app-src/` (빌드: `scripts/build-app.sh`, Android SDK build-tools와 android-19 필요)
- 차에 올리기 전 PC 테스트: `sh tests/stub-test.sh`. 가짜 헤드유닛 환경에서 설치·되돌리기·리포트를 검사합니다.
- 차 테스트용 USB 스크립트: `scripts/`
- 규칙:
  - 사용자 안내는 한국어로 씁니다.
  - 차 테스트와 배포 전에 코드 리뷰를 합니다.
  - 실패하면 기존 상태를 유지하고, 항상 되돌릴 방법을 둡니다.
  - 비밀번호·폰 이름·VIN 같은 개인정보는 기록하지 않습니다.
