# 내 차 제보 가이드

Korea Projection은 **한국 차라면 일단 켜 봅니다**. 설치하면 HMG-API가 내 차에서 지도를 만들어 맞는지 확인하고, 맞으면 무선 카플레이와 무선 안드로이드 오토를 켭니다.

그래서 이 글은 이럴 때 씁니다.

- **되면:** "됐다"고 알려 주세요. 지원 목록에 **✅ 확인됨**으로 올립니다.
- **안 되면:** 아래 파일 3개를 보내 주세요. 그 안의 기록으로 원인을 찾습니다.

저희는 여러분의 차를 직접 만져 볼 수 없습니다. **보내 주시는 파일 3개가 전부입니다.** 천천히 따라 해 주세요.

> ⚠️ **Korea Projection이 만든 폴더(`KoreaProjection-report`)만 올려 주세요.**
> 다른 도구(HMG-API Car Report 원본, 다른 패키지의 진단 묶음 등)가 만든 파일에는 **블루투스 주소·기기 이름**이 들어 있을 수 있습니다. 공개 이슈에 올리면 누구나 볼 수 있고, 지워도 남을 수 있습니다.

> 걸리는 시간: 차에서 5분, 컴퓨터에서 5분
> 필요한 것: USB 메모리 1개, 컴퓨터 1대, GitHub 계정(무료)

---

## 준비물 확인

아래 네 가지가 모두 "예"이면 시작하세요.

| 확인할 것 | 어떻게 확인하나요? |
|---|---|
| 내비에 **NEMESIS**가 있나요? | 내비 화면에 **NEMESIS Manager**가 보이면 됩니다. |
| **HMG-API**가 설치되어 있나요? | NEMESIS Manager → **My Packages** 목록에 **HMG-API**가 보이면 됩니다. |
| **Korea Projection**이 설치되어 있나요? | 같은 목록에 **Korea Projection: Wireless for Korean Cars**가 있으면 됩니다. 예전 버전이면 먼저 [최신 버전](https://github.com/StopDragon/korea-projection/releases/latest)으로 업데이트해 주세요. 설치는 [설치 가이드](install-guide.md)를 보세요. |
| USB 메모리가 **FAT32**인가요? | 설치할 때 쓴 USB를 그대로 쓰면 됩니다. |

## 1단계: 차에서 파일 만들기 (5분)

1. **차를 세우고** 시동을 켭니다.
2. 내비 화면이 다 뜰 때까지 **1~2분 기다립니다.**
3. USB를 꽂습니다.
   - "Korea Projection을 설치할까요?" 같은 창이 뜨면 **아니요**를 누릅니다.
4. 내비에서 **NEMESIS Manager**를 엽니다.
5. **My Packages** → **Korea Projection: Wireless for Korean Cars** → **Launch**를 누릅니다. 상태 화면이 뜹니다.
   - 화면 제목의 판(예: Korea Projection 1.7.3)이 [최신 릴리스](https://github.com/StopDragon/korea-projection/releases/latest)보다 낮으면 먼저 업데이트해 주세요.
6. 화면의 **[제보 파일 만들기]** 버튼을 누릅니다. (1.7.3부터 Launch만 눌러서는 제보 파일이 생기지 않습니다.)
   - "설치가 끝난 뒤 눌러 주세요."가 나오면 설치가 끝날 때까지(3~5분) 기다렸다가 다시 누르세요.
   - "USB를 꽂은 뒤 다시 눌러 주세요."가 나오면 USB가 꽂혔는지 확인하세요.
7. 진행 막대가 뜹니다.
   > 제보 자료 저장 중 N% · … (USB를 빼지 마세요)
   - 처음 몇 초는 "요청을 기다리는 중입니다(길면 1분쯤)."가 보일 수 있습니다. 그대로 기다리세요. 2분이 지나도 시작하지 않으면 "제보 파일을 만들지 못했습니다…"로 바뀝니다.
8. **그대로 1~2분 기다립니다.** USB를 빼지 마세요. 시동도 끄지 마세요.
9. 초록색으로 이 글자가 뜨면 끝입니다. 이제 USB를 빼세요.
   > 완료: 제보 자료를 USB의 KoreaProjection-report 폴더에 저장했습니다. 이제 USB를 빼셔도 됩니다.
   - 화면에 [제보 파일 만들기] 버튼이 없으면 예전 버전입니다(1.7.2까지는 Launch를 누르면 바로 만들었습니다). 최신 버전으로 업데이트한 뒤 다시 해 주세요.

**빨간 글자("USB에 저장하지 못했습니다…", "제보 파일을 만들지 못했습니다…", "USB가 없습니다…")가 뜨면:** USB를 뺐다가 다시 꽂고, 5번(Launch)부터 다시 하세요.
- "리포트(1·3번 파일)는 저장했지만 Car Report는 저장하지 못했습니다(…). 이제 USB를 빼셔도 됩니다."가 뜨면 USB를 빼셔도 됩니다. 파일 2개만 있어도 보내 주세요.

## 2단계: 파일 3개 확인하기 (컴퓨터)

USB를 컴퓨터에 꽂고 엽니다. **`KoreaProjection-report`라는 폴더**가 있습니다. 그 폴더를 엽니다.

```
USB
└─ KoreaProjection-report        ← 이 폴더를 엽니다
   ├─ 1-report.md                ← 차 정보
   ├─ 2-car-report.json          ← 차 안 프로그램 위치 정보
   └─ 3-log.txt                  ← 무슨 일이 있었는지 적힌 기록
```

**파일 3개가 모두 있으면 됩니다.** 다른 파일이나 폴더(예: `HMG-API reports`)는 올리지 마세요.

- `1-report.md` 첫 줄에 "설치 진행 중에 만든 리포트입니다"가 있으면, 설치가 끝난 뒤 [제보 파일 만들기]로 다시 만들어 주세요.

- 파일이 2개뿐이고 `2-car-report.json`이 없으면, 1단계를 한 번 더 해 주세요. 그래도 없으면 있는 파일만 보내 주세요.
- ⚠️ **`4-debug-private.txt`는 보내지 마세요.** 디버그를 켠 차에만 생기는 운행 기록입니다(1.7.1). 1.7.2부터는 `KoreaProjection-private`이라는 다른 폴더에 저장되니, 그 폴더도 올리지 마세요.

### 개인정보가 걱정되면

`1-report.md`와 `3-log.txt`는 메모장(Mac은 텍스트 편집기)으로 열어 읽어 볼 수 있습니다.

- **들어 있지 않은 것:** Wi-Fi 이름, Wi-Fi 비밀번호, 휴대폰 이름, 차대번호(VIN)
- 휴대폰 블루투스 주소와 IP 주소는 `xx:xx:xx:xx:xx:xx`, `x.x.x.x`처럼 **이미 지워져** 있습니다. `2-car-report.json`의 IP 주소도 1.7.2부터 지웁니다(1.7.1 이하에서 만든 파일은 IP가 남아 있을 수 있습니다).
- USB의 `HMG-API reports` 폴더에 있는 원본 파일은 IP를 가리지 않은 것이라 **공개 이슈에 올리지 마세요.** 제보 폴더(`KoreaProjection-report`)의 파일만 올려 주세요.
- 전화번호·연락처 이름은 `[가림: 번호]`·`[가림: 연락처]`, 목적지·교차로 이름과 좌표는 `[가림: 위치]`·`[가림: 좌표]`로 바뀌어 있습니다. 어디를 다녔는지는 남지 않습니다.
- 그래도 내 정보가 보이면 그 줄을 지우고 저장한 뒤 보내 주세요. 그리고 저희에게도 알려 주세요.

## 3단계: 보내기 (컴퓨터, 5분)

**같은 차종의 제보는 이슈 하나에 모읍니다.** 그래야 같은 차 정보를 한눈에 보고 빨리 고칠 수 있습니다. 아래 두 방법 중 편한 것으로 하세요.

1. **양식으로 올리기(가장 쉬움):** **[차량 제보 양식](https://github.com/StopDragon/korea-projection/issues/new?template=car-report.yml)**을 열어 칸을 채우고 제출합니다. **같은 차종 이슈가 있으면 자동으로 그 이슈에 옮겨지고**, 새 이슈는 안내와 함께 닫힙니다.
   - 내비 화면의 **QR을 폰으로 찍으면** 내비 소프트웨어 버전과 상태 요약이 미리 채워진 양식이 열립니다. 파일은 나중에 컴퓨터에서 옮겨진 차종 이슈에 댓글로 붙이면 됩니다.
   - GitHub에 로그인하라고 나오면 로그인합니다. 계정이 없으면 무료로 만들 수 있습니다.
2. **차종 이슈에 바로 댓글 달기:** **[차종별 제보 이슈 목록](https://github.com/StopDragon/korea-projection/issues?q=label%3A%22%F0%9F%93%8C+%EC%B0%A8%EC%A2%85+%EC%9D%B4%EC%8A%88%22)**에서 내 차를 찾아(제목 끝 코드가 `1-report.md` "펌웨어" 줄의 앞부분과 같으면 내 차) 댓글로 쓰는 폰, 무선 카플레이·무선 안드로이드 오토·계기판 결과, Launch 화면 맨 위 문구를 적고 파일을 붙입니다.
3. 양식 칸 설명: 쓰는 폰, 설치 단계, Launch 화면 맨 위 문구(그대로), 무선 카플레이·무선 안드로이드 오토·계기판 결과를 고릅니다. 쓰지 않는 폰의 칸은 "이 폰은 안 씀", 계기판을 안 써 봤으면 "써 보지 않음/모름"을 고르세요. 그 밖에 모르는 칸은 비워도 됩니다.
4. **파일을 한꺼번에 넣는 방법**
   - `KoreaProjection-report` 폴더를 엽니다.
   - 키보드로 **모두 선택**합니다. Windows는 `Ctrl` + `A`, Mac은 `⌘` + `A`
   - 1.7.1이면 `4-debug-private.txt`는 선택에서 빼 주세요(Windows `Ctrl`+클릭, Mac `⌘`+클릭).
   - 선택한 파일을 마우스로 끌어서 댓글 칸(또는 양식의 "제보 파일" 칸)에 놓습니다. 파일 이름이 나타나면 성공입니다.

**적지 마세요:** 비밀번호, 차대번호(VIN), 전화번호, 휴대폰 이름

설치 방법처럼 내 차 결과가 아닌 질문은 **[설치·사용 질문](https://github.com/StopDragon/korea-projection/issues/new?template=question.yml)** 양식을 써 주세요.

## 그다음에는

### 처음 설치했을 때 (목록에 없는 차)

1. [설치 가이드](install-guide.md)대로 설치합니다.
2. 설치하고 **3~5분** 기다립니다. 내 차에서 지도를 만드는 데 시간이 조금 더 걸립니다.
3. 이 글자가 뜨면 준비된 것입니다.
   > 무선 카플레이 설정을 마쳤습니다. 내비를 재부팅해 주세요(RESET 버튼 또는 NEMESIS 재부팅).
   - 유선 카플레이까지 안 되면 Korea Projection을 삭제하세요.
   - "지도를 만들지 못했습니다"나 "지도 확인에 실패했습니다"가 뜨면, 이 차에서는 아직 켤 수 없다는 뜻입니다. 아무것도 바뀌지 않았습니다. 이 가이드대로 파일 3개를 보내 주세요.
4. **내비를 재부팅합니다.** 시동만 끄면 내비가 꺼지지 않을 수 있습니다. 차를 세운 상태에서 Launch 화면의 **[지금 재부팅]**([제보 파일 만들기] 옆)을 누르거나, 내비 본체의 **RESET 버튼**(작은 구멍)을 클립으로 누르거나, **NEMESIS Manager**에서 **재부팅**을 누르세요. 재부팅한 뒤에는 2분 넘게 켜 두세요(짧게 여러 번 재부팅하면 HMG-API가 무선 기능을 끕니다). ([자세히](install-guide.md#내비-재부팅하는-법))
5. 아이폰은 **설정 → 일반 → CarPlay**로, 안드로이드 폰은 무선 안드로이드 오토로 연결해 봅니다([안드로이드 연결법](install-guide.md#안드로이드-폰-연결-무선-안드로이드-오토)).
6. **결과를 알려 주세요.** 이 가이드의 1~3단계대로 내 차 이슈에 댓글로 남기면 됩니다. 연결됐으면 QR로 "연결됨"만 알려 주셔도 지원 목록에 올립니다.

### 되면

지원 목록을 **"✅ 확인됨"**으로 바꿉니다. 다른 차주분들도 바로 쓸 수 있게 됩니다. 감사합니다!

### 안 되면

보내 주신 `3-log.txt`를 보고 원인을 찾습니다. 한두 번 더 부탁드릴 수 있습니다.

- 언제든 원래대로 돌릴 수 있습니다. NEMESIS Manager에서 이 패키지(Korea Projection: Wireless for Korean Cars)를 **삭제(Uninstall)**하면 됩니다. 저희가 설치했던 무선 모드도 함께 지웁니다.
- **유선 카플레이(USB 케이블)는 언제나 그대로 쓸 수 있습니다.**

## 자주 묻는 것

| 질문 | 답 |
|---|---|
| 왜 차마다 이 파일이 필요한가요? | 무선 카플레이는 내비 안의 순정 프로그램에 끼어들어 켭니다. 끼어들 위치가 차종·소프트웨어 버전마다 다를 수 있어서, 그 차에서 직접 찾은 위치가 필요합니다. |
| 같은 차종인데 연식이 달라요 | 내비 소프트웨어 버전이 다르면 따로 필요합니다. `1-report.md`의 "펌웨어" 줄을 비교해 보세요. 같으면 이미 지원될 수 있습니다. |
| 목록에 없는 차종인데 켜도 괜찮나요? | 켜기 전에 HMG-API가 내 차에서 지도를 만들어 **맞는지 먼저 확인**합니다. 맞지 않으면 켜지 않습니다. 켠 뒤에 문제가 있으면 Korea Projection을 삭제하면 원래대로 돌아갑니다. |
| 내비를 업데이트했더니 안 돼요 | 소프트웨어 버전이 바뀌면 다시 제보가 필요할 수 있습니다. 이 가이드대로 다시 보내 주세요. |
| 차에 위험하지 않나요? | 해외 차와 Wi-Fi 부품이 없는 차에서는 아무것도 바꾸지 않습니다. 바꾼 것은 HMG-API가 원본을 백업해 두었다가 삭제할 때 그대로 되돌립니다. 제보 파일은 읽기만 해서 만듭니다. |
| HMG-API 공식판에는 언제 들어가나요? | HMG-API에도 영어로 제안합니다. 반영되면 공식 모드로 옮깁니다. 그 전까지는 Korea Projection에 든 "한국 차 빌드"를 씁니다. |
