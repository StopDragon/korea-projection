# Korea Projection 설치 가이드 (처음 하시는 분용)

컴퓨터에 익숙하지 않아도 따라 할 수 있게 한 단계씩 적었습니다. 순서대로 하시면 됩니다.

> ⚠️ 차량 소프트웨어를 바꾸는 일입니다. 모든 책임은 차 주인에게 있습니다.
> 설치는 **차를 세운 상태**에서만 하세요.

## 한눈에 보기

1. 준비물 확인 (NEMESIS, HMG-API)
2. USB를 **FAT32**로 포맷
3. **USB용 설치 파일**(`korea-projection-버전-usb.zip`) 받기
4. 압축을 풀고 **안에 있는 것**을 USB **맨 위**에 복사 (안쪽 `korea.projection.zip`은 풀지 않기)
5. 내비 화면이 다 뜬 뒤 USB를 꽂고 **예** 누르기
6. USB를 빼고 **3~5분 기다리기** (NEMESIS Manager → Launch 화면에 "무선 카플레이 설정을 마쳤습니다" 알림)
7. **내비 재부팅** (Launch 화면의 [지금 재부팅] 버튼, RESET 버튼 또는 NEMESIS Manager의 재부팅. 시동만 끄면 부족합니다)
8. 아이폰은 무선 카플레이, 안드로이드 폰은 무선 안드로이드 오토로 연결

가장 많이 틀리는 곳은 **4번**입니다. 아래 [4단계](#4단계-usb에-복사하기)의 그림을 꼭 확인하세요.

---

## 1단계: 준비물 확인

| 준비물 | 설명 |
|---|---|
| 지원 차량 | 차주 제보로 확인된 차는 [README 지원 차량](../README.md#지원-차량) 표에 있습니다(니로·그랜저·쏘나타·K5·K7·쏘렌토·스팅어·벨로스터 N·K3 등). 그 밖의 한국 차도 설치하면 자동으로 시도해 봅니다 |
| NEMESIS | 1.16 이상이 차에 설치되어 있어야 합니다. 설치 방법: [NEMESIS 안내](https://github.com/xwtk/hmg_nemesis) |
| HMG-API | 1.0.2 이상이 차에 설치되어 있어야 합니다. 설치 방법: [HMG-API 안내](https://github.com/Open-HMG/HMG-API) |
| HMG-API 무선 모드 | **따로 설치하지 않아도 됩니다.** Korea Projection이 자동으로 설치합니다 |
| USB 메모리 | **32GB 이하**를 쓰세요. 그보다 크면 Windows에서 FAT32로 포맷할 수 없습니다 |
| 컴퓨터 | Windows PC 또는 Mac |
| 폰 | 무선 카플레이를 지원하는 아이폰, 또는 무선 안드로이드 오토를 지원하는 안드로이드 폰 |

**NEMESIS와 HMG-API가 이미 있는지 확인하는 법:** 내비에서 NEMESIS Manager를 열고 My Packages에 **HMG-API**가 보이면 됩니다.

`wireless.projection` 패키지는 **필요 없습니다.** 설치되어 있으면 먼저 삭제해 주세요.

## 2단계: USB를 FAT32로 포맷하기

> ⚠️ 포맷하면 USB 안의 파일이 **모두 지워집니다.** 필요한 파일은 먼저 옮겨 두세요.
> 블랙박스·음악용으로 쓰던 USB보다는 **설치 전용 USB**를 따로 쓰시는 게 편합니다.

### Windows

1. USB를 PC에 꽂습니다.
2. 파일 탐색기(폴더 모양 아이콘)를 열고 왼쪽에서 **내 PC**를 누릅니다.
3. USB 드라이브(예: `USB 드라이브 (E:)`)를 **마우스 오른쪽 버튼**으로 누르고 **포맷...**을 고릅니다.
4. **파일 시스템**을 **FAT32**로 바꿉니다.
   - 목록에 FAT32가 없다면 USB가 32GB보다 큰 것입니다. 32GB 이하 USB를 쓰세요(exFAT·NTFS는 고르지 마세요).
5. **빠른 포맷**에 체크된 그대로 **시작**을 누르고, 경고가 나오면 **확인**을 누릅니다.

### Mac

1. USB를 Mac에 꽂습니다.
2. **디스크 유틸리티**를 엽니다(Spotlight에서 "디스크 유틸리티" 검색).
3. 왼쪽 목록에서 USB를 고르고 위쪽 **지우기**를 누릅니다.
4. 다음처럼 고르고 **지우기**를 누릅니다.
   - 이름: 아무거나 (예: `NEMESIS`)
   - 포맷: **MS-DOS(FAT)** (ExFAT이 아닙니다)
   - 방식(보이는 경우): **마스터 부트 레코드**

## 3단계: 설치 파일 받기

1. [최신 릴리스 페이지](https://github.com/StopDragon/korea-projection/releases/latest)를 엽니다.
2. 아래 **Assets**에서 **`korea-projection-버전-usb.zip`**을 받습니다(예: `korea-projection-1.7.3-usb.zip`).

| 파일 | 누가 받나요 |
|---|---|
| `korea-projection-버전-usb.zip` | **대부분의 사용자는 이것을 받으세요.** USB에 넣을 것이 모두 들어 있습니다 |
| `korea.projection-버전.zip` | 패키지만 들어 있습니다. 직접 `NEMESIS.data`를 만들거나 셸로 설치하는 분용입니다 |
| `korea-projection-버전-rollback-usb.zip` | 무선 모드를 예전 판으로 되돌리는 USB입니다. 새 판에 문제가 있을 때만 씁니다([아래](#무선-모드를-예전-판으로-되돌리기)) |

`NEMESIS.data` 파일은 직접 만들지 않으셔도 됩니다. USB용 설치 파일 안에 미리 만들어 넣었습니다.
(메모장으로 직접 만들면 이름이 `NEMESIS.data.txt`가 되어 차가 알아보지 못하는 일이 많았습니다.)

## 4단계: USB에 복사하기

### USB 안이 이렇게 되어야 합니다

```
USB (맨 위)
├─ NEMESIS.data
├─ README.txt
└─ packages            ← 폴더
    └─ korea.projection.zip   ← 압축 파일 그대로 (풀지 않음)
```

USB를 열었을 때 **`NEMESIS.data`와 `packages` 폴더가 바로 보여야** 합니다.

### 이렇게 하면 안 됩니다

| 잘못된 모양 | 왜 안 되나요 |
|---|---|
| `USB/korea-projection-1.7.3-usb/NEMESIS.data` | 폴더째로 넣었습니다. 차는 USB **맨 위**의 `NEMESIS.data`만 찾습니다 |
| `USB/korea-projection-1.7.3-usb.zip` | 압축을 풀지 않았습니다 |
| `USB/packages/korea.projection/NEMESIS.data …` | 안쪽 `korea.projection.zip`까지 풀었습니다. 이 파일은 **zip 그대로** 있어야 합니다 |
| `USB/korea.projection.zip` (packages 폴더 없음) | 차는 `packages/korea.projection.zip` 위치에서 찾습니다 |
| `USB/NEMESIS.data.txt` | 이름 끝에 `.txt`가 붙었습니다. 받은 파일을 그대로 쓰세요 |

### Windows에서

1. 받은 `korea-projection-버전-usb.zip`을 **마우스 오른쪽 버튼**으로 누르고 **압축 풀기...**(또는 **모두 압축 풀기**)를 고릅니다.
2. 새 폴더가 열립니다. 그 폴더 **안으로 들어가서** `NEMESIS.data`, `README.txt`, `packages`가 보이는지 확인합니다.
3. `Ctrl + A`로 세 개를 모두 고르고 `Ctrl + C`로 복사합니다.
4. USB 드라이브를 열고(**아무 폴더에도 들어가지 않은 상태**) `Ctrl + V`로 붙여 넣습니다.
5. `packages` 폴더를 열어 `korea.projection.zip`이 **압축 파일 모양 그대로** 있는지 확인합니다. 열어 보거나 풀지 마세요.

반디집·알집 같은 프로그램을 쓰신다면 "여기에 풀기"보다 **"폴더명으로 풀기"**를 고른 뒤, 위 2~5번처럼 폴더 **안의 것**을 USB로 옮기세요.

### Mac에서

1. Safari로 받으면 자동으로 압축이 풀려 **다운로드 폴더에 `korea-projection-버전-usb` 폴더**가 생깁니다.
   - 압축이 풀리지 않고 `.zip`으로 남아 있다면 두 번 눌러 푸세요.
2. 그 폴더 **안으로 들어가서** `NEMESIS.data`, `README.txt`, `packages`를 모두 고릅니다(`⌘ + A`).
3. Finder 왼쪽의 USB로 **끌어다 놓습니다.** USB 창을 열었을 때 세 개가 바로 보여야 합니다.
4. `packages` 폴더 안의 `korea.projection.zip`은 **두 번 누르지 마세요.** 누르면 Mac이 압축을 풀어 버립니다. 풀린 폴더가 생겼다면 그 폴더만 지우고 zip은 남겨 두세요.

### 다 넣었으면

- 한 USB에는 한 패키지만 설치할 수 있습니다. 전에 HMG-API 같은 다른 패키지를 설치하던 USB라면, 복사할 때 `NEMESIS.data`를 **덮어쓰기**하세요.
- 컴퓨터에서 USB를 **안전하게 제거**(Windows: 작업 표시줄의 USB 아이콘 → 꺼내기 / Mac: Finder에서 꺼내기 ⏏)한 뒤 뽑습니다.

## 5단계: 차에 설치하기

1. 차를 세우고 시동(또는 전원)을 켭니다.
2. **내비 화면이 다 뜰 때까지** 1~2분 기다립니다.
3. USB를 차의 USB 단자에 꽂습니다.
4. 화면에 Korea Projection을 설치할지 묻는 창이 뜨면 **60초 안에 예**를 누릅니다.
   - 시간이 지나면 저절로 취소됩니다. USB를 뺐다가 다시 꽂으면 다시 묻습니다.
   - 지원 목록에 없는 차는 경고 색으로 표시될 수 있습니다. 그래도 설치되고, 한국 차라면 자동으로 시도합니다.
5. 설치가 끝났다는 안내가 나오면 **USB를 뺍니다.**
   - USB를 꽂아 둔 채로 두면 유선 연결을 먼저 시도해서 무선 연결이 안 될 수 있습니다.
6. **3~5분 기다립니다.** 이 동안 재부팅하지 마세요. Korea Projection이 HMG-API 무선 모드와 그 차의 지도를 자동으로 갖춥니다. 지원 목록에 없는 차는 내 차에서 지도를 만드느라 조금 더 걸립니다.
   - 진행 상황과 안내는 **NEMESIS Manager → My Packages → Korea Projection: Wireless for Korean Cars → Launch** 화면에 나옵니다(뜰 때까지 5~10초). 진행 막대 아래 노란 **알림** 줄에 안내가 남습니다.
   - **"무선 카플레이 설정을 마쳤습니다. 내비를 재부팅해 주세요"** 알림이 보이면 다음으로 넘어갑니다.
   - 이미 다 갖춰진 차(업데이트 등)에서는 이 안내 없이 바로 다음으로 넘어가도 됩니다.
   - "HMG-API 앱에서 변경 사항을 적용…" 같은 다른 알림이 보이면, 차를 세운 상태에서 그 안내를 따른 뒤 다음으로 넘어갑니다.
   - Wi-Fi를 한 번도 켜지 않은 차는 **"무선 카플레이 준비로 Wi-Fi를 한 번 켭니다"** 알림이 남고, 카플레이·블루투스가 잠시 끊길 수 있습니다. 처음 한 번만 그렇습니다.
   - "지도를 만들지 못했습니다" 알림이 보이면 내비를 재부팅한 뒤 [제보](car-report-guide.md)해 주세요. 차에는 아무것도 바뀌지 않았습니다.
   - Wi-Fi 관련 판정("Wi-Fi를 켜는 중", "부품이 없어", "칩이 켜지지 않아")은 아래 [상태 화면 읽는 법](#상태-화면-읽는-법)을 보세요.
   - 순정 핫스팟을 켜 둔 차는 그동안 무선 설정을 미룹니다. 순정 핫스팟을 끄고 내비를 재부팅하면 진행합니다.
7. **내비를 재부팅합니다**(내비가 완전히 꺼졌다 켜지게 하려는 것입니다). 아래 [내비 재부팅하는 법](#내비-재부팅하는-법)을 보세요.

### 내비 재부팅하는 법

**시동을 끄는 것만으로는 부족합니다.** 시동을 꺼도 내비(헤드유닛)는 한동안 켜져 있을 수 있어서, 설정이 반영되지 않습니다. 아래 둘 중 하나로 내비를 완전히 다시 켜 주세요.

- **방법 1: RESET 버튼**
  - 내비 본체에 있는 **RESET 버튼(작은 구멍)**을 클립이나 볼펜 끝으로 **꾹** 누릅니다.
  - 위치는 차마다 다릅니다. 보통 전원·볼륨 버튼 근처에 있습니다.
- **방법 2: NEMESIS Manager**
  - **NEMESIS Manager**를 열고 **재부팅**을 누릅니다.
- **방법 3: [지금 재부팅] 버튼 (1.7.3부터)**
  - Launch 화면의 **[제보 파일 만들기]** 옆에 **[지금 재부팅]** 버튼이 늘 있습니다. 누르고 확인 창에서 **재부팅**을 누릅니다. 두 번째 재부팅("3분 뒤 한 번 더 재부팅해 주세요")에도 쓸 수 있습니다.
  - **차를 세운 상태에서만** 누르세요. 화면이 1~2분 꺼졌다 켜집니다.
  - 제보 파일을 만드는 중에는 막힙니다("제보 파일을 다 만든 뒤 눌러 주세요.").
  - "설정을 마무리하는 중입니다. 잠시 뒤 다시 눌러 주세요."는 설치나 설정 마무리(HMG-API 적용 포함)가 아직 도는 중이라는 뜻입니다. 잠시(1분쯤) 기다렸다가 다시 누르세요. 설치 중이라 거절되는 일이 네 번째까지 이어지면 RESET 안내로 바뀝니다.
  - "재부팅 요청을 받지 못했습니다. 다시 눌러 주세요."가 나오면 한 번 더 누르세요.
  - "2분 안에 재부팅을 반복하면 HMG-API가 무선 기능을 끕니다. 내비가 켜지고 2~5분 뒤에 다시 눌러 주세요."가 나오면 내비가 켜진 지 2~5분 지난 뒤 다시 누르세요. HMG-API의 부팅 보호에 걸리지 않게 막는 것입니다.
  - "NEMESIS에서 Launch를 다시 누른 뒤 눌러 주세요."가 나오면 Launch 화면을 연 지 오래된 것입니다(10분쯤). NEMESIS Manager에서 Launch를 다시 누른 뒤 버튼을 누르세요.
  - "재부팅하지 못했습니다. RESET 버튼이나 NEMESIS 재부팅을 써 주세요."가 나오면(눌러도 80초쯤 꺼지지 않을 때 등) 방법 1·2를 쓰세요.

화면이 꺼졌다가 처음부터 다시 뜨면 된 것입니다(1~2분 걸립니다).

> ⚠️ **재부팅을 짧게 여러 번 하지 마세요.** 켜진 뒤 2분 안에 재부팅을 반복하면 HMG-API가 무선 기능을 끄는 부팅 보호가 걸립니다. 재부팅한 뒤에는 **2분 넘게 켜 두세요.**

## 6단계: 아이폰 연결과 확인

1. 아이폰에서 **설정 → 일반 → CarPlay**를 엽니다.
2. **사용 가능한 차량**에 차가 보이면 누릅니다. 처음 한 번은 블루투스 연결을 함께 묻습니다.
3. 내비 화면에 카플레이가 뜨면 성공입니다.

**잘 되는지 확인하려면:** 내비에서 NEMESIS Manager → My Packages → **Korea Projection: Wireless for Korean Cars** → **Launch**를 누르세요.

- 맨 위가 **초록색**이면 준비된 상태입니다.
- 노랑·빨강이면 화면의 문구를 확인하고, [내 차 제보 가이드](car-report-guide.md)대로 제보해 주세요. 화면의 **QR을 폰 카메라로 찍으면** 내용이 채워진 제보 양식이 열립니다.

### 상태 화면 읽는 법

1.7.3부터 Launch 화면이 이렇게 보입니다.

- **제목:** "Korea Projection 1.7.3"처럼 설치된 판이 나옵니다. [최신 릴리스](https://github.com/StopDragon/korea-projection/releases/latest)보다 낮으면 먼저 업데이트해 주세요.
- **맨 위 판정 줄(색):** 지금 상태와 할 일을 한두 문장으로 알려 줍니다.
  - "설치 중입니다. 끝날 때까지 기다려 주세요." → 기다리세요. 이때는 QR 대신 안내가 나옵니다.
  - "무선 카플레이·안드로이드 오토 준비됨. …" / "무선 카플레이 준비됨(안드로이드 오토는 준비 중). …" / "무선 카플레이 준비됨. …"(초록) → 폰을 연결하세요. 안드로이드 오토를 꺼 둔 차는 마지막 문구입니다.
  - "무선 카플레이·안드로이드 오토 연결됨" / "무선 카플레이 연결됨, 안드로이드 오토 준비됨" / "무선 카플레이 연결됨" / "무선 안드로이드 오토 연결됨, 카플레이 준비됨"(초록) → 지금 연결된 상태입니다.
  - "…(재부팅 1번이면 끝납니다)." / "…재부팅하고 3분 뒤 한 번 더 재부팅해 주세요(남은 재부팅 2번)." → 남은 횟수만큼 재부팅하세요. 업데이트 뒤에는 "무선 모드를 새 판(2.4.1)으로 바꿨습니다. 내비를 재부팅해 주세요(재부팅 1번이면 끝납니다)."처럼 나옵니다. QR 대신 안내가 나오며, **[지금 재부팅]**을 누르면 됩니다.
  - "무선 모드를 새 판으로 바꾸는 중입니다. 3분 뒤 한 번 더 재부팅해 주세요(남은 재부팅 1번)." → 3분 기다린 뒤 한 번 더 재부팅하세요.
  - "무선 모드를 이번에는 새 판으로 바꾸지 못했습니다. 재부팅하면 다시 시도합니다." → 한 번 더 재부팅하세요. 다음 부팅에 다시 바꿉니다.
  - "Wi-Fi를 켜는 중입니다(재부팅 뒤 한 번 더 확인)…" → Wi-Fi가 꺼져 있거나 늦게 켜진 차입니다. Korea Projection이 다시 켜 보니 재부팅해 주세요. 문구 끝의 "(확인 1/3)"처럼 세 번째 부팅까지 확인합니다.
  - "이 차의 내비에는 Wi-Fi 부품이 없어…" / "이 차는 Wi-Fi 칩이 켜지지 않아…" → 이 차에서는 무선 카플레이를 쓸 수 없습니다. 아래 회색 줄에 지우는 법이 나옵니다. 이런 차를 위해 **USB Wi-Fi 동글로 쓰는 방법을 준비하고 있습니다**(아직 날짜는 정해지지 않았습니다).
  - "먼저 할 일: …"(노랑) → 같은 차에서 된 분이 있거나 내비 버전이 옛것인 경우입니다. 그 안내부터 해 주세요.
  - "HMG-API가 재부팅이 너무 잦은 것으로 보고 무선 기능을 껐습니다. …"(빨강) → HMG-API의 부팅 보호가 걸렸습니다. 저절로 풀리지 않습니다. **HMG-API를 지우지 말고** NEMESIS에서 HMG-API를 다시 설치(업데이트)한 뒤 재부팅하고, 2분 넘게 켜 두세요. 요약 줄은 "설치: HMG-API 훅 꺼짐(부팅 보호)"입니다.
  - "HMG-API를 다시 설치한 것으로 보입니다. 내비를 재부팅하고 2분 넘게 켜 두세요."(노랑) → 다시 설치는 됐습니다. 재부팅하고 2분 넘게 켜 두면 풀립니다.
- **요약 3줄:** 판정 아래에 "설치: …", "무선 Wi-Fi: …", "폰 연결: …"이 나옵니다. 제보할 때 이 세 줄을 함께 적어 주시면 좋습니다.
- **자세히(제보용):** 그 아래 회색 표는 제보용 자세한 상태입니다.
- **[제보 파일 만들기]:** USB를 꽂고 누르면 제보 파일을 만듭니다([제보 가이드](car-report-guide.md)).

**길안내를 계기판에 띄우려면:** 카카오맵·카카오내비·네이버 지도는 그대로 됩니다. T맵은 앱의 전체 → 연구소 → **"카플레이 HUD 연동"**을 켜 주세요.

**곡 정보:** 무선 카플레이에서도 계기판·미디어 위젯에 곡 제목이 나옵니다. 끄려면 HMG-API 앱의 무선 모드 설정에서 "Song info on wireless CarPlay"를 끕니다.

## 안드로이드 폰 연결 (무선 안드로이드 오토)

1. 폰의 안드로이드 오토 앱 설정에서 **무선 Android Auto**를 켭니다.
2. **처음 한 번은** 내비와 폰 양쪽에서 블루투스 등록을 지우고 새로 등록합니다.
3. 내비에 "무선 Android Auto 사용" 안내가 뜨면 **사용**을 누릅니다.
4. 폰이 차의 Wi-Fi에 저절로 붙고, 내비에 안드로이드 오토 화면이 뜹니다(30초~1분).

- 아이폰과 함께 쓰는 차는 먼저 붙은 폰 하나만 연결됩니다. 안드로이드 폰으로 하시려면 아이폰의 블루투스를 잠시 꺼 주세요.
- 무선 안드로이드 오토를 끄고 싶으면 USB 맨 위에 빈 파일 `kp-aa-off`를 만들어 꽂고 Launch를 누르세요. 다시 켜려면 `kp-aa-on`.
- 니로 하이브리드·니로 플러그인 하이브리드에서 확인했습니다. K3·K8처럼 내비가 직접 카플레이 Wi-Fi를 켜는 차는 이 기능을 쓰지 않습니다. 다른 차는 결과를 제보해 주세요.

## 업데이트하는 법

설치와 똑같습니다. 새 버전의 `korea-projection-버전-usb.zip`을 받아 4~5단계를 그대로 하세요.
USB에 이전 파일이 있으면 **덮어쓰기**하면 됩니다. 업데이트할지 물으면 **예**를 누르세요.

- 업데이트가 끝나면 Launch 화면 제목의 판(예: Korea Projection 1.7.3)이 바뀌었는지 확인하세요.
- **"Operation failed"가 나오면 USB 문제인 경우가 많습니다.** 다른 USB를 FAT32로 포맷해 다시 해 보세요. USB를 바꾸니 설치된 사례가 있습니다([#79](https://github.com/StopDragon/korea-projection/issues/79), [#144](https://github.com/StopDragon/korea-projection/issues/144)).
- 그래도 안 되면 NEMESIS Manager에서 Korea Projection을 **Uninstall** → [내비 재부팅](#내비-재부팅하는-법) → 새 판을 설치하세요.

- 새 버전에 새 무선 모드가 들어 있으면 Korea Projection이 HMG-API 무선 모드도 함께 바꿉니다. Launch 화면에 **"새 판으로 바꾸기 대기 중"**이 보이면 맨 위 판정 줄의 안내대로 내비를 재부팅해 주세요("HMG-API 앱에서 변경 사항을 적용" 안내가 있으면 적용한 뒤 재부팅).
- 1.5.5 이하에서 업데이트한 뒤 아이폰이 자동으로 붙지 않으면: 아이폰 **설정 → Wi-Fi**에서 차의 카플레이 네트워크 옆 ⓘ → **"이 네트워크 지우기"**를 누르고 내비를 재부팅하세요. 핫스팟이 5GHz로 바뀌었기 때문입니다. 설정 → 일반 → CarPlay의 차 등록은 지우지 마세요.

### 무선 모드를 예전 판으로 되돌리기

새 무선 모드에서 카플레이가 이상해졌다면 릴리스의 **`korea-projection-버전-rollback-usb.zip`**을 씁니다.

> ⚠️ **설치한 판과 같은 판의 되돌리기 USB만 쓰세요.** 예: 1.7.3을 설치했으면 v1.7.3 릴리스의 되돌리기 USB를 씁니다. 다른 판의 USB는 무선 모드를 바꾸지 않거나(1.7.3용 USB), 무선 안드로이드 오토를 멈추게 할 수 있습니다(옛 v1.7.0·v1.7.1용 USB는 릴리스에서 내렸습니다).

| 설치한 판 | 쓸 되돌리기 USB | 되돌리는 무선 모드 |
|---|---|---|
| 1.7.3 | v1.7.3 릴리스의 `korea-projection-1.7.3-rollback-usb.zip` | 2.4.1 → 2.4.0 (1.7.2의 무선 모드) |
| 1.7.2 | v1.7.2 릴리스의 `korea-projection-1.7.2-rollback-usb.zip` | → 2.3.0 |

- 스포티지 NQ5는 1.7.2용 되돌리기 USB(2.3.0)를 쓰지 마세요. 2.3.0에서는 NQ5의 무선 카플레이가 동작하지 않았습니다.
- 1.7.3용 USB로 2.4.0으로 되돌리면 1.7.3에서 고친 무선 모드 문제(안드로이드 오토 자동 연결 등)가 다시 생길 수 있습니다. 제보할 때 되돌렸다고 함께 적어 주세요.

1. 압축을 풀고 **안에 있는 것**을 USB 맨 위에 복사합니다(설치 USB와 같은 방법, 다른 USB를 쓰는 게 편합니다).
2. 차를 세운 상태에서 내비 화면이 다 뜬 뒤 USB를 꽂고, 화면 안내를 따릅니다(묻는 창이 뜨면 **예**).
3. 1분쯤 뒤 Launch 화면(상태 화면)에 "되돌리기 USB: …" 안내가 나옵니다.
   - 1.7.3용: **"무선 모드를 2.4.0으로 되돌리고 고정했습니다. 내비를 재부팅해 주세요."**가 보이면 USB를 빼고 내비를 재부팅합니다.
   - "HMG-API 앱에서 변경 사항을 적용한 뒤 재부팅해 주세요"가 보이면, 차를 세운 채로 HMG-API 앱에서 적용하고 재부팅합니다.
   - "Korea Projection이 설정을 확인하는 중입니다" 안내가 나오면 3분쯤 뒤에 USB를 다시 꽂아 주세요.
   - 중간에 USB가 빠지거나 내비가 꺼졌으면 같은 USB를 다시 꽂으세요. 이어서 진행하고 "이미 2.4.0으로 고정되어 있어 남은 적용을 마쳤습니다. 내비를 재부팅해 주세요."(또는 "…HMG-API 앱에서 변경 사항을 적용한 뒤 재부팅해 주세요.")가 나옵니다.
   - 되돌리지 못하면 아무것도 바뀌지 않고 지금 판 그대로 남습니다. 결과는 USB의 `kp-rollback/RESULT.txt`에도 남습니다.

되돌린 판은 고정되어 다음 업데이트에서도 자동으로 바뀌지 않습니다. 고정을 풀려면 같은 USB의 `kp-rollback` 폴더 안에 빈 파일 `UNPIN`을 만들어 다시 꽂고, 내비를 재부팅합니다. 결과는 [제보](car-report-guide.md)로 알려 주세요.

## 삭제하는 법

NEMESIS Manager → My Packages → **Korea Projection: Wireless for Korean Cars** → **Uninstall**을 누른 뒤 [내비를 재부팅](#내비-재부팅하는-법)합니다.

- Korea Projection이 설치한 무선 모드와 핫스팟·설정을 정리하고, 잠갔던 Wi-Fi 설정을 원래대로 되돌립니다.
- 유선 카플레이(USB 케이블)는 그대로 쓸 수 있습니다.

## 잘 안 될 때

| 증상 | 확인할 것 |
|---|---|
| USB를 꽂아도 아무 창도 안 뜸 | ① USB가 **FAT32**인지 ② `NEMESIS.data`가 USB **맨 위**에 있는지(폴더 안 X) ③ 이름이 `NEMESIS.data.txt`가 아닌지 ④ 내비 화면이 다 뜬 뒤에 꽂았는지 ⑤ NEMESIS가 차에 설치되어 있는지 |
| 한 번 취소했더니 다시 안 물어봄 | 같은 USB는 꽂을 때 한 번만 묻습니다. **뺐다가 다시 꽂으세요** |
| 패키지를 찾을 수 없다는 오류 | `packages/korea.projection.zip`이 그 위치·그 이름으로 있는지, 압축을 풀어 버리지 않았는지 확인하세요 |
| 설치는 됐는데 카플레이가 안 뜸 | ① USB를 뺐는지 ② [내비를 재부팅](#내비-재부팅하는-법)했는지(시동만 끄면 안 될 수 있음) ③ HMG-API가 설치되어 있는지 ④ Launch 상태 화면의 색과 알림 줄 |
| "아이폰이 차 Wi-Fi에 오지 않습니다…" 노란 안내 | 아이폰 설정 → Wi-Fi에서 차 네트워크를 지우고 다시 연결하세요 |
| "폰이 차 Wi-Fi에 연결됐지만 카플레이가 시작되지 않았습니다…" 노란 안내 | 내비를 재부팅하세요. 재부팅 뒤에도 같으면 [제보](car-report-guide.md)해 주세요 |
| "HMG-API가 재부팅이 너무 잦은 것으로 보고 무선 기능을 껐습니다…" | 짧은 시간에 재부팅을 반복해 HMG-API 부팅 보호가 걸렸습니다. **HMG-API를 지우지 말고** NEMESIS에서 HMG-API를 다시 설치(업데이트) → 재부팅 → 2분 넘게 켜 두세요. HMG-API를 지운 뒤 설치하면 무선 모드가 꺼진 채 남을 수 있습니다 |
| 재부팅을 여러 번 했더니 무선이 꺼짐 | 켜진 뒤 2분 안에 재부팅을 반복하지 마세요. 위 줄처럼 부팅 보호에 걸렸는지 Launch 화면 맨 위 문구를 확인하세요 |
| 업데이트 뒤 아이폰이 안 붙음 | 아이폰 설정 → Wi-Fi에서 차의 카플레이 네트워크를 **"이 네트워크 지우기"** 한 뒤 내비 재부팅([위](#업데이트하는-법)) |
| "wireless.projection을 삭제한 뒤 내비를 재부팅해 주세요" 안내 | NEMESIS Manager에서 `wireless.projection`을 삭제하고 내비를 재부팅하세요. 부팅 뒤 Korea Projection이 무선 기능 파일을 다시 맞추고 재부팅 안내를 남기면, 한 번 더 재부팅합니다 |
| "HMG-API 앱에서 그 모드만 지우고(HMG-API는 지우지 말고)…" 안내 | 차에 맞지 않는 다른 무선 모드(예: 북미 차용 기본판)가 있습니다. HMG-API는 그대로 두고 HMG-API 앱에서 그 모드만 지우고 적용 → 재부팅하면 Korea Projection이 한국 차용 모드를 넣습니다 |
| "Wi-Fi 장치가 계속 켜지지 않습니다…" | 일부 그랜저 IG에서 생기는 문제로, 아직 고치지 못했습니다. 내비를 재부팅해 보시고, 그래도 같으면 [제보](car-report-guide.md)해 주세요 |
| "Wi-Fi를 켜는 중입니다(재부팅 뒤 한 번 더 확인)" | 내비를 재부팅하세요. 세 번째 부팅까지 다시 확인합니다 |
| "Wi-Fi 부품이 없어…" / "Wi-Fi 칩이 켜지지 않아…" | 이 차에서는 쓸 수 없습니다. 화면의 지우는 법대로 Uninstall 뒤 재부팅하면 원래대로 돌아갑니다(유선 카플레이는 그대로). USB Wi-Fi 동글로 쓰는 방법을 준비하고 있습니다 |
| 안드로이드 오토가 안 붙음 | ① 내비·폰 양쪽 블루투스 등록을 지우고 다시 등록했는지 ② 아이폰이 먼저 붙어 있지 않은지 ③ `kp-aa-off`로 꺼 두지 않았는지 |
| 목록에 없는 한국 차인데 안 됨 | 설치하면 자동으로 시도하지만, 지도가 맞지 않거나 Wi-Fi 부품이 없으면 켜지 않습니다. [내 차 제보 가이드](car-report-guide.md)대로 파일 3개를 보내 주시면 원인을 찾습니다 |
| 내비가 휴대폰 핫스팟(일반 Wi-Fi)에 안 붙음 | 정상입니다. 무선 카플레이용 핫스팟이 켜져 있는 동안에는 Wi-Fi를 함께 쓸 수 없습니다 |

그래도 안 되면 내 차 결과는 [내 차 제보 가이드](car-report-guide.md)대로, 설치 방법 질문은 [설치·사용 질문](https://github.com/StopDragon/korea-projection/issues/new?template=question.yml)으로 알려 주세요. 차종, 내비 소프트웨어 버전, Launch 화면 문구를 함께 적어 주시면 빨리 볼 수 있습니다.
비밀번호, 휴대폰 이름, 차대번호(VIN)는 **적지 마세요.**

## 자주 묻는 질문

**시동을 껐는데 무선 카플레이 Wi-Fi가 계속 보여요.**
정상입니다. 시동을 꺼도 내비가 완전히 꺼질 때까지(차마다 몇 분) Wi-Fi가 켜져 있습니다. 순정 내비도 같습니다.

**계기판(HUD)에 길안내가 안 나와요.**
카플레이 계기판 안내는 **지도 앱이 안내 정보를 차로 보낼 때만** 나옵니다. 앱마다, 같은 앱도 설정에 따라 다릅니다(T맵은 "카플레이 HUD 연동"을 켜야 함). 차를 세워 두면 앱이 안내를 보내지 않을 수도 있으니 주행 중에 확인해 주세요.

**계기판 그림이 순정 내비와 달라요.**
계기판·HUD 길안내는 **폰의 지도 앱이 보내 주는 정보까지만** 나와서 순정 내비와 똑같지는 않습니다. 폰이 보내는 것은 다음 회전의 종류·방향·남은 거리·도로 이름 정도라, 지하차도·고가차도 구분, 일부 갈림길(Y자)·회전교차로 모양, 방면 표시는 순정과 다르거나 안 나올 수 있습니다. **지도 앱마다 보내는 정보가 달라서**(애플 지도·T맵·카카오내비·네이버 지도·구글 지도) 같은 길도 앱에 따라 그림이 다르고, 앱이 안내를 보내지 않으면(정차 중, 앱·iOS 판에 따라) 나오지 않습니다. 틀린 그림을 보이기보다 작은 화살표로 보이게 한 곳도 있습니다(회전을 지난 직후 등). 순정과 다르게 나오는 곳은 **지도 앱 이름, 어떤 길(지하차도·회전교차로 등), 그때 만든 제보 파일**과 함께 알려 주세요.

앱별로 무엇이 나오는지는 아직 제보로 확인된 것이 적어 표로 만들지 않았습니다. 확인된 것만 모아 표로 만들겠습니다.

**안드로이드 오토 음악이 순정 미디어와 오가며 끊겨요.**
내비의 **블루투스 설정 → 블루투스 오디오 전환 → "휴대폰에서 전환 허용 안 함"**을 골라 보세요. 순정의 자동 전환 기능과 부딪쳐서 생깁니다.

**연결이 자꾸 안 되거나 예전 차 등록이 남아 있어요.**
폰과 내비 양쪽에서 이 차(블루투스·CarPlay) 등록을 지우고 다시 등록해 보세요. 아이폰은 설정 → 일반 → CarPlay와 설정 → 블루투스에서 지웁니다.

**순정 설정의 기기 목록이 "등록된 기기가 없습니다"로 나와요. ☆ 버튼을 누르면 "기기 연결 안내"가 떠요.**
정상입니다. 순정 연결 방식이 아니라서 생기는 표시입니다. 팝업은 **취소**를 누르고 그대로 쓰시면 됩니다.

**같은 차종인데 다른 분은 되고 제 차는 Wi-Fi 부품이 없대요.**
같은 차종이라도 생산 시기·트림에 따라 내비에 Wi-Fi 부품이 없는 차가 있습니다. 상태 화면이 "Wi-Fi 부품이 없어…"라고 하면 그 차는 무선 카플레이를 쓸 수 없습니다. 판정이 의심되면 내비 버전이 된 차와 같은지 먼저 확인해 주세요.

**NEMESIS를 설치할 수 없어요.**
엔지니어링 모드에 OTA 메뉴가 없는 차(예: 아반떼 N 2024 `CN7NPE`)는 NEMESIS를 설치할 수 없어 이 패키지도 쓸 수 없습니다. NEMESIS 설치 문의는 [NEMESIS](https://github.com/xwtk/hmg_nemesis) 쪽에 해 주세요.

## 직접 만들고 싶은 분 (고급)

USB용 설치 파일 대신 패키지 zip(`korea.projection-버전.zip`)만 쓰려면:

1. 받은 파일 이름을 `korea.projection.zip`으로 바꿔 USB의 `packages` 폴더에 넣습니다.
2. USB 맨 위에 `NEMESIS.data`를 만들고 아래 세 줄을 넣습니다. 파일 이름 끝에 `.txt`가 붙지 않게 하세요(Windows는 탐색기 **보기 → 파일 확장명**을 켜면 보입니다).

```ini
[nemesis]
type=install
path=packages/korea.projection.zip
```

셸을 쓸 수 있다면: `nemesis install /storage/usb0/packages/korea.projection.zip`
