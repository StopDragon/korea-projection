G70 2022 / A3000mini 무선 CarPlay 보조 패키지 0.4.1 (실험판)

적용 범위: IKFL.KOR.0000.V039.001.260902 / tcc803x / 3.18.24-tcc,
ipTIME A3000mini 실제 USB ID 0bda:b812, 인터페이스 ff/ff/ff.
NEMESIS, HMG-API와 공식 Korea Projection 1.7.4를 별도로 설치해야 합니다.
다른 펌웨어/제품 ID로의 적용은 확인하지 않았습니다.

0.4.0에서는 실제 CarPlay 화면, DHCP 임대 1개, AP 접속 1대를 확인했습니다.
음악은 계속 재생되지만 화면이 멈추고 반응하지 않는 증상이 남아 있습니다.
사용자가 멈춘 화면을 종료하려고 연결을 강제로 끊었습니다. 그 종료 기록은
자연 단절의 증거가 아닙니다. 화면 멈춤의 원인은 미확인이고 안정화 전입니다.
0.4.1은 공개 저장소용 소스 정리와 USB 선택 검사를 추가한 개발판입니다.
호스트 시험은 통과했으나 이 개발판 전체의 실차 재시험은 아직 없습니다.
드라이버와 AP 채널 149/HT40 설정은 0.4.0과 같습니다.

브리지는 검증한 드라이버를 먼저 등록하고 확인한 인터페이스를 wlan0으로
제공합니다. 무선 모드의 검증·설치·적용과 hostapd 실행은 KP가 담당합니다.
KP DHCP가 없을 때 보완 DHCP를 제공하며, DHCP 소켓 충돌이 확인될 때만
1067번 포트와 IP 주소를 보존하는 포트 변환을 사용합니다. 준비된 AP에
정책 표 60/61의 AP 대역 경로가 없을 때만 추가하고 기존 경로는 보존합니다.
구성 요소의 출처와 라이선스는 NOTICE.txt를 확인하세요.

설치 / 기존 Bridge 0.1.0~0.4.0에서 업데이트
1. 정차 상태에서 진행합니다. 기존에 저장한 기록이 있으면 먼저 복사합니다.
   Driver Probe 등 충돌하는 Wi-Fi 보조 패키지가 있으면 먼저 삭제하고
   내비를 재부팅합니다. HMG-API와 Korea Projection은 유지합니다.
2. 바깥 ZIP을 풀고 내용물을 USB 최상위에 복사합니다. packages 안 ZIP은
   풀지 않습니다. Package Store에서 Bridge와 Logs를 모두 설치/업데이트합니다.
   NX4HEV용 사용자 수정본 Korea Projection 1.7.4.1은 설치 대상이 아닙니다.
3. USB 메모리를 빼고 A3000mini를 꽂은 뒤 내비를 한 번 재부팅합니다.
   동글을 유지한 채 5분 이상 기다립니다. KP가 무선 모드를 설치/적용할 수
   있으므로 Launch의 진행 안내를 확인하고 재부팅 요청이 있으면 따릅니다.
   짧은 간격의 재부팅을 반복하지 않습니다.
4. 아이폰의 Wi-Fi와 Bluetooth를 켜고 설정 → 일반 → CarPlay에서 연결합니다.
   내비와 아이폰의 Bluetooth/CarPlay 사용 요청을 허용합니다.
   이전 단독 AP 시험의 G70-USB-WIFI-TEST에 수동 접속할 필요는 없습니다.
5. Bridge → Launch에서 상태를 확인하고 화면·음악·터치 동작을 시험합니다.
   아이폰 Wi-Fi의 IP가 169.254.x.x이거나 비어 있으면 정상 임대가 아닙니다.
   KP의 초록색 '준비됨'은 DHCP 임대나 정상적인 미디어 재생까지 보장하지 않습니다.
   멈춤이 나면 추가 재부팅 전에 아래 Logs 절차로 현재 결과를 저장합니다.

두 패키지의 Launch 차이
- G70 USB Wi-Fi Bridge: 상태 확인. 로그 모드로 바꾸거나 동작을 중단하지 않습니다.
- G70 Wi-Fi Logs: 기록 저장 후 다음 부팅에서 브리지를 일시 정지합니다.
  데이터 포트 하나에서 동글을 USB 메모리로 바꿔 기록을 옮기기 위한 기능입니다.

데이터 포트 하나에서 결과 복사
1. 동글을 꽂고 시험한 상태에서 Logs → Launch.
   초기 대기 안내가 나오면 부팅 후 5분까지 기다렸다 다시 실행합니다.
2. '현재 기록을 저장했습니다' 안내 후 동글을 유지한 채 내비를 재부팅합니다.
   이번 부팅에서는 브리지가 드라이버를 올리지 않습니다.
3. Logs → Launch로 드라이버가 내려간 것을 확인합니다.
4. 동글을 빼고 이 설치 USB를 꽂은 뒤 Logs → Launch로 복사합니다.
5. G70_BRIDGE_... 폴더와 EXPORT_COMPLETE.txt를 확인합니다.
   복사가 성공하면 다음 부팅에서 브리지를 재개하도록 준비됩니다.
6. USB를 빼고 동글을 다시 꽂은 뒤 내비를 재부팅합니다.

연결 시작/종료, 인터페이스 소실, 부팅 3/5분 상태는 자동 보존합니다.
이전 두 번의 브리지 동작 부팅을 유지합니다. 내보내는 자료는 상태·개수·고정
오류 분류이며 SSID/비밀번호, MAC/IP, 폰 이름, 원본 logcat/dmesg와 DHCP
임대 파일은 내보내지 않습니다. 기존 USB 기록은 컴퓨터에 보관할 수 있습니다.

삭제 / 되돌리기
1. 필요한 기록을 USB에 복사합니다.
2. Logs → Bridge 순으로 삭제한 뒤 내비를 재부팅합니다.
3. 자체 소유 표시·규칙·경로를 정리하고 모듈은 재부팅으로 내립니다.
   KP/HMG-API의 모드·설정 제거는 각 패키지의 삭제 절차를 따릅니다.
드라이버 로드 중 문제가 나 보호 상태가 되면 재설치를 반복하지 말고 Logs로
기록을 남깁니다. 실행 중 rmmod는 사용하지 않습니다.
