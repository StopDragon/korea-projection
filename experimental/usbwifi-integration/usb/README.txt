Korea Projection 1.7.4.2 — 개인용 자동 USB Wi-Fi 통합판
2026-11-21 (한국 시간), 원개발자 공식 배포가 아닙니다.

차종 이름으로 USB 지원을 제한하지 않습니다.
1. 실제 내장 BCM/SDIO Wi-Fi가 있으면 기존 내장 Wi-Fi 경로를 우선합니다.
2. USB VID:PID와 ff/ff/ff 인터페이스로 AC/AX 드라이버를 선택합니다.
3. Android 4.4.2 국내 펌웨어, tcc803x, 3.18.24-tcc, 모듈 적재 허용,
   실제 커널 설정 gzip·순정 bcmdhd 지문과 드라이버별 필수 export를 검사합니다.
4. 일치하는 조합에서만 조건부 적재·소유 인터페이스 이름 지정·AP/DHCP를 시도합니다.
   커널 설정 MD5: 1fd51a10a44ae9ff77fa9ecc94192026
   순정 bcmdhd MD5: 7da276f0d683eecc6c302068331ef274
   지문/심볼 일치는 완전한 ABI 증명이 아니므로 다른 차량의 실차 성공을 뜻하지 않습니다.
5. AP 기능/149번 채널을 읽기 전용으로 조회합니다. 명확한 미지원은 중단하고,
   조회 불가 시 실제 hostapd의 AP 활성화를 별도로 확인합니다.
6. 순정 지도/모드의 HMG-API 호환 검사를 계속 적용합니다. 알 수 없는 커널/설정,
   tcc897x, 누락된 진단 자료, 다른 프로세스 소유 장치는 이유를 남기고 진단 대상으로 둡니다.

기존 시험 자료의 반영
- G70 + A3000mini: 기존 연결 성공 구성의 AP/DHCP/포트 우회와 인터페이스 소유권 처리.
  EV6 4.14 베타의 RX TCP 체크섬 검증 AC 드라이버가 기본입니다.
  기존 0.4.0 AC 드라이버도 비교용으로 보관했습니다. 화면 멈춤 해결은 미확인입니다.
- 제공된 NX4HEV 1.7.4.1: 원본 서명 무선 모드 2.4.6, HT20 설정,
  Bluetooth iAP2 전환 중 재키잉을 최대 90초 미루는 처리를 유지합니다.
  제공된 GRT 드라이버는 보관하지만, 차종 이름만으로 자동 적재하지 않습니다.
  공통 호환 검사 통과 시 새 공통 드라이버/AP/DHCP 경로를 사용합니다.
- MANN1309 EV6 4.14.0 베타: 체크섬 AC 드라이버, AX 커널 적응 패치,
  원본 서명 AA 유지 보조 모드와 소스·출처를 포함합니다.
  보조 모드만 CVEV/사양/GPM·services odex 검사 통과 때 설치합니다.
  원 프로젝트의 실차 검증 대상은 AA이며, 이 통합판의 EV6 CarPlay는 미확인입니다.

13b1:0045 2001:331c 2001:331e 2001:331f 20f4:808a 2357:0115

공통 AX ID (RTL8831BU/RTL8851BU, G70 포함 같은 검사로 조건부 시도)
0bda:b831 0bda:b851 2001:332a 2c4e:0128 3625:010b 7392:e611
AX900mini는 제조사 자료상 RTL8831BU입니다. 제품명만 믿지 않고 실제 ID를 확인합니다.
기존 EV6 바이너리는 b831이 없어, Realtek 작성 Linux 및 공개 vendor 소스의
같은 RTL8851B 매칭을 근거로 소스 패치 후 별도 컴파일한 드라이버를 포함합니다.
G70 AX900mini의 실물 AP/CarPlay 시험은 아직 하지 않았습니다.
0bda:b832는 다른 RTL8852BU 계열이어서 이 드라이버에 매칭하지 않습니다.
0bda:1a2b 등 CD 모드는 자동 전환하지 않으며 진단 이유를 표시합니다.
지원 USB Wi-Fi 동글은 하나만 꽂습니다. 교체할 때는 내비를 재부팅합니다.
17개 AC 및 6개 AX 전체를 실물로 시험한 것이 아닙니다.

포함된 무선 모드
- 기본: 제공된 KP 1.7.4의 원본 서명본 2.4.5.
- NX4HEV 260902: 제공된 1.7.4.1의 원본 서명본 2.4.6.
- 해당 EV6: ev6-kr-aa-keep 원본 서명본, 원래 순정 파일 검사 유지.
APK 본체/서명은 유지했습니다. 앱 하단 '앱 1.7.4'는 원본 뷰어 버전이며,
NEMESIS 패키지 버전은 1.7.4.2입니다.

검증 이력 기억
- 차량의 KP 백업 저장소에 마지막 선택과 실제 관측 단계를 원자적으로 저장합니다.
- 바인딩/AP/DHCP lease/프로젝션 제어 TCP를 구분합니다. 준비됨/TCP를 화면 정상이나
  안정성 성공으로 저장하지 않습니다. 화면/안정 시간은 사용자의 별도 확인 값입니다.
- 제품/펌웨어, 플랫폼/Android/커널/설정, 순정·선택 드라이버, 실제 USB ID/클래스,
  HMG 지도/모드, 통합 코드가 바뀌거나 실패하면 재검증합니다.
- 재사용에도 실제 동글 존재·필수 호환·현재 부팅의 적재 증명·소유권을 다시 확인합니다.
- VIN/MAC/SSID/암호는 이력에 저장하지 않습니다.
- Logs가 내보낸 RESULT_CONFIRMATION.txt에 실제 화면 확인 결과를 기록할 수 있습니다.
  display_confirmed=yes, stable_minutes=실제 확인 분, problem=none 으로 바꾸고
  설치 USB 최상위에 KP_RESULT_CONFIRMATION.txt라는 이름으로 둡니다.
  화면 멈춤이면 display_confirmed=no, stable_minutes=0, problem=screen_freeze.
  다음 Logs 복사 때 읽으며, 동일 지문과 다음 실제 장치 재검증 통과 때 반영합니다.
  화면 멈춤 보고는 자동 준비됨만으로 지워지지 않습니다.

G70에서 기존 Bridge 0.4.0 구성에서 옮기기
1. 필요한 기존 기록을 G70 Wi-Fi Logs로 저장하고 복사합니다.
   데이터 포트 하나: 기존 Logs로 저장 → 동글 유지한 채 재부팅 → 드라이버가
   내려간 것을 확인 → 동글 대신 USB 메모리를 꽂아 기존 Logs로 복사합니다.
2. NEMESIS에서 'G70 Wi-Fi Logs' → 'G70 USB Wi-Fi Bridge' 순으로 삭제합니다.
   Korea Projection과 HMG-API 및 현재 무선 모드는 유지합니다.
3. 내비를 재부팅해 이전 동글 드라이버를 내립니다.

NX4HEV의 기존 개인용 1.7.4.1은 업데이트 후 재부팅합니다. 이전 GRT 드라이버가
메모리에 남아 있으면 소유권 검사로 중단합니다. 새 공통 경로는 별도 실차 재검증 대상입니다.
EV6에서 usbwifi.hotspot 등 별도 동글 패키지를 쓰고 있었다면 그 패키지만 먼저
삭제하고 재부팅합니다. HMG-API와 KP의 무선 모드는 별도로 삭제하지 않습니다.
다른 jmk-wifi / usbwifi.hotspot / Driver Probe 등의 동시 실행은 막습니다.

설치 (정차 상태)
1. 바깥 ZIP을 풀고 '안의 내용'을 FAT32 USB 최상위에 복사합니다.
   USB를 열면 NEMESIS.data, packages/, KP_USB_EXPORT.txt가 바로 보여야 합니다.
   packages 안 ZIP은 풀지 않습니다.
2. USB의 Package Store에서 'Korea Projection 1.7.4.2 Personal'을 설치/업데이트합니다.
   'KP USB Wi-Fi Logs'도 설치합니다. 이 Logs는 Wi-Fi 연결 서비스가 아닙니다.
3. USB를 빼고 동글 하나를 꽂은 다음 내비를 한 번 재부팅합니다.
   기존 드라이버가 메모리에 남아 있을 수 있어 재부팅이 필요합니다.
4. 5분 기다리고 Korea Projection → Launch에서 설치 진행을 확인합니다.
   설정 완료 후 재부팅 요청이 있으면 따릅니다. 짧은 간격으로 재부팅하지 않습니다.
5. 기존 Bluetooth/CarPlay/Android Auto 등록으로 연결을 확인합니다.
   새 등록이 필요하면 휴대폰과 차 양쪽에서 이전 등록을 지우고 다시 등록합니다.
   원래 무선 모드를 일부러 꺼 두거나 고정한 상태는 자동으로 우회하지 않습니다.

데이터 포트 하나에서 새 기록 복사
1. 동글을 꽂아 시험한 상태에서 KP USB Wi-Fi Logs → Launch.
   설치 진행 중에는 완료 후 실행합니다. 가능하면 멈춘 시각도 기록합니다.
2. 저장 완료 안내 뒤 동글을 유지한 채 내비를 재부팅합니다.
   이 부팅은 드라이버/AP를 올리지 않는 기록 복사 모드입니다.
3. Logs 안내를 확인한 뒤 동글을 이 설치 USB로 바꾸고 Logs를 다시 Launch합니다.
4. KP_USB_... 폴더와 EXPORT_COMPLETE.txt를 확인합니다.
5. USB를 빼고 동글을 다시 꽂아 내비를 재부팅하면 연결 모드로 돌아갑니다.
일반 KP Launch는 상태 확인이며, 이 Logs Launch가 저장/일시 정지 전환입니다.

G70 드라이버 비교/되돌리기
- 기본은 rxcheck(수신 TCP를 커널이 검사하는 개선 드라이버)입니다.
- 기존 0.4.0 드라이버로 비교하려면 설치 USB 최상위에 빈 파일
  KP_G70_BASELINE_DRIVER.txt를 만들고 KP를 같은 버전으로 업데이트한 뒤 재부팅합니다.
- 개선판을 다시 선택할 때는 위 파일을 지우고 KP_G70_RXCHECK_DRIVER.txt를 만들고
  같은 방법으로 업데이트·재부팅합니다. 두 선택 파일을 동시에 두지 않습니다.
- 선택 파일이 없으면 기존 선택을 유지합니다. 동작 중 모듈을 교체하지 않습니다.

검증 범위
통합판 전체를 세 차량에서 다시 실행한 결과는 아직 없습니다. 연결 성공 이력은
G70의 이전 0.4.0, 제공된 NX4HEV 계열, EV6 원 프로젝트의 AA 시험 결과입니다.
음악이 나오는데 화면만 멈추는 G70 증상의 정확한 원인은 미확인입니다. 사용자가
강제로 끊은 세션 종료 기록을 자연 단절로 판단하지 않습니다. 새 로그에는 영상
스택 오류 분류, CPU/네트워크, USB 연결 속도·송수신 바이트·오류 및 TCP 체크섬 오류
숫자를 추가했습니다. 드라이버가 제공하면 무선 품질·신호 원시 숫자도 보관합니다.
개인정보가 포함될 수 있는 원본 로그를 공개 업로드하는 동작은 없습니다.

삭제/되돌리기
- 기록을 먼저 복사하고 Logs → Korea Projection 순으로 삭제 후 재부팅합니다.
- 자체 소유 표시·규칙·모드는 각 검사 후 정리합니다. 모듈은 재부팅으로 내립니다.
- 전체 이전 구성으로 돌아가려면 이전 KP/보조 패키지를 원래 순서로 설치합니다.
출처와 변경 범위는 THIRD-PARTY.txt, 해시는 SHA256SUMS와 RELEASE.json을 확인하세요.

적재/반복 실패 보호
미완료 적재·적재 실패는 자동 재시도하지 않습니다. AP가 설정 완료 후 5분 내 활성화되지
않으면 그 부팅의 시도를 멈추고, 세 부팅 연속 실패 시 보호 상태를 유지합니다.
다시 시험할 때는 Logs 복사 모드로 재부팅해 모듈이 내려간 상태에서 설치 USB 최상위에
빈 KP_USB_RETRY_DRIVER.txt를 두고 같은 버전을 업데이트합니다. 재시도 후 이 파일은
지웁니다. 이 선택도 필수 호환/소유권 검사를 생략하지 않으며, 실행 중 모듈은 내리지 않습니다.
