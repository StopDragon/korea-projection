# 무선 모드 되돌리기 USB 안내 (Korea Projection 1.8.0·1.8.1용)

Korea Projection 1.8.0·1.8.1이 넣은 무선 모드(1.8.0은 2.4.6, 베타 2부터 2.4.8, 정식은 2.4.9, 1.8.1은 2.4.10)에서 카플레이·안드로이드 오토가 이상할 때, 1.7.4 정식의 무선 모드(2.4.5)로 되돌리고 고정합니다.
고정해 두면 1.8.0이 부팅할 때 1.8.0 버전으로 다시 바꾸지 않습니다.
2.4.6은 2.4.5와 코드가 같고, USB Wi-Fi 동글 차를 받는 줄 하나만 더한 버전입니다. 2.4.8은 여기에 계기판 길안내 고침과 동글 부팅 처리를 더한 버전이고, 2.4.9는 순정 방화벽이 있는 차에서 무선 안드로이드 오토 연결을 허용하는 규칙을 더한 버전이고, 2.4.10은 무선 안드로이드 오토 준비 다시 보내기·계기판 길안내·기록을 보강한 버전입니다. 되돌리면 기능은 1.7.4 정식과 같아집니다.
계기판 회전 안내만 이상하면 되돌리기 전에 HMG-API 앱의 이 모드 설정에서 `tbt_fit`(앱에는 "Turn-by-turn fitted to the Hyundai/Kia navigation (near-turn view, distance bar)"로 보입니다)을 꺼 보세요. 2.4.5와 2.4.6 모두 같은 설정입니다.
1.7.4를 쓰는 분은 v1.7.4 릴리스의 되돌리기 USB(2.4.1로 되돌림)를, 1.7.3을 쓰는 분은 v1.7.3 릴리스의 USB(2.4.0으로 되돌림)를 쓰세요. 설치한 버전과 같은 버전의 USB만 씁니다.

> **USB Wi-Fi 동글로 무선 카플레이를 쓰는 차(내장 Wi-Fi 부품이 없는 차)는 이 USB를 쓰지 마세요.** 2.4.5에는 동글 차 줄이 없어 HMG-API가 설치를 받지 않습니다. 그때는 아무것도 바꾸지 않고 "지금 버전 그대로"라고 알립니다.

## 준비

- USB 맨 위에 `NEMESIS.data`, `NEMESIS.sh`, `kp-rollback` 폴더(안에 `wireless-carplay-aa-2.4.5.zip`)를 넣습니다.
- **반드시 정차한 상태에서** 합니다. 운행 중에는 하지 마세요.
- **시동을 켜고 내비 화면이 다 뜬 뒤 2분 지나서 USB를 꽂으세요.** '실행할까요?' 창이 1분 안에 안 뜨면 USB를 빼고 다시 꽂으세요.
- Korea Projection 1.8.0 이상이 설치되어 있어야 합니다. 무선 모드가 2.4.6·2.4.8·2.4.9·2.4.10일 때만 바꾸고, 다른 버전(2.4.5 이하, 2.4.7, 2.4.11 이상)의 무선 모드는 바꾸지 않습니다.
- **나중에 "USB Wi-Fi 동글 사용"을 켤 차라면, 켜기 전에 아래 "고정 풀기"를 먼저 하세요.** 2.4.5에 고정된 채로는 동글 차 항목이 없어 HMG-API가 무선 모드를 받지 않습니다.

## 되돌리기 (한 번 꽂기)

1. 정차하고 시동을 켭니다. 내비 화면이 다 뜬 뒤 2분 지나서 USB를 꽂고, 실행할지 물으면 "예"를 누릅니다. 창이 1분 안에 안 뜨면 USB를 빼고 다시 꽂습니다.
2. 1분쯤 기다린 뒤 Korea Projection 상태 화면(QR 화면)을 엽니다. "되돌리기 USB: …" 안내가 보입니다.
3. "2.4.5로 되돌리고 고정했습니다. 재부팅해 주세요"가 보이면 USB를 빼고 재부팅합니다.
4. "HMG-API 앱에서 변경 사항을 적용한 뒤 재부팅해 주세요"가 보이면, 정차한 채로 HMG-API 앱에서 적용하고 재부팅합니다.

결과는 USB의 `kp-rollback/RESULT.txt`에도 남습니다. 상태 화면·제보 리포트에는 "무선 모드 고정: 2.4.5"로 보입니다. 상태 화면을 열지 못했으면 PC에서 이 파일을 읽어 보세요.
자세한 기록은 `kp-rollback/log/`에 있습니다(비밀번호·SSID·폰 이름·MAC은 남기지 않습니다).

## 고정 풀기 (다시 1.8.0의 무선 모드로)

1. USB의 `kp-rollback` 폴더에 빈 파일 `UNPIN`을 만듭니다(이름만 맞으면 내용은 없어도 됩니다).
2. 정차한 상태에서(시동을 켜고 내비 화면이 다 뜬 뒤 2분 지나서) USB를 꽂고 "예"를 누릅니다. 창이 1분 안에 안 뜨면 USB를 빼고 다시 꽂습니다. "고정을 풀었습니다. Korea Projection 1.8.0 이상이 설치돼 있으면 재부팅 약 3분 뒤 새 버전으로 다시 바뀝니다."가 보이면 USB를 뺍니다.
3. 재부팅하면 약 3분 뒤 Korea Projection이 무선 모드를 설치된 패키지의 버전(1.8.0 정식은 2.4.9, 1.8.1은 2.4.10)으로 다시 바꿉니다.
4. 상태 화면에 "HMG-API 앱에서 변경 사항을 적용"이 보이면, 정차한 채로 앱에서 적용하고 재부팅합니다.

`UNPIN` 파일을 지우지 않고 다시 꽂으면 또 고정 풀기만 합니다. 되돌리기를 다시 하려면 `UNPIN`을 지웁니다.

## 주의

- **1.7.4용 되돌리기 USB(2.4.1로 고정)를 썼던 차:** 그 고정은 1.8.0으로 올려도 그대로 남아 무선 모드가 2.4.1에 머뭅니다(상태 화면·리포트에 "무선 모드 고정: 2.4.1"). 1.8.0의 무선 모드를 쓰려면 위 "고정 풀기"를 한 뒤 재부팅하세요(이 USB의 `UNPIN`으로 풀 수 있습니다).
- 설치가 실패하면 아무것도 바꾸지 않습니다(HMG-API 엔진은 설치에 실패하면 원래 모드 폴더를 그대로 둡니다). 설치 뒤 적용만 실패하면 2.4.5와 고정은 남고, HMG-API 앱에서 적용하라는 안내가 나옵니다.
- 이 USB는 토스트를 띄우지 않습니다. 결과는 상태 화면과 `RESULT.txt`로 봅니다.
- 순정 방화벽이 있는 차에서 내비 순정 Wi-Fi로 무선 프로젝션을 쓰는 경우(예: 캐스퍼 EV)는 2.4.5로 되돌리면 무선 안드로이드 오토가 다시 막힐 수 있습니다. 2.4.9부터 들어간 방화벽 허용 규칙이 2.4.5에는 없기 때문입니다.
- 2.4.6과 2.4.5는 동글 차 항목 하나만 다릅니다(2.4.8·2.4.9는 길안내 고침도 다르고, 2.4.9는 방화벽 허용 규칙도 다릅니다). 1.8.0에서 생긴 문제가 무선 모드 때문이 아니면(상태 화면·연결 시간 등) 되돌려도 그대로입니다. 그럴 때는 되돌리기보다 [제보 파일 만들기]로 알려 주세요. 고정하면 다음 새 버전도 자동으로 받지 않으니, 문제가 풀리면 "고정 풀기"를 하세요.
- 차에서 아직 시험하지 않았습니다(PC 가짜 환경 시험만 했습니다).
