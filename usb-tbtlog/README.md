# 계기판 길안내 기록 USB 안내

이 USB는 **순정 내비로 길안내를 받으며 달리는 동안** 순정 내비가 계기판에 보내는 안내(회전 그림 번호·방향·거리)를 USB에 적습니다.
Korea Projection의 카플레이·안드로이드 오토 계기판 안내를 순정과 같게 맞추는 데 씁니다.

순정 내비가 보내는 값은 차종마다 다를 수 있습니다. 그래서 **니로 하이브리드가 아닌 차**의 기록이 특히 도움이 됩니다.

## 먼저 읽어 주세요: 기록되는 것 (동의)

**zip을 받아 USB에 넣고 꽂으면 아래 내용이 USB에 기록됩니다.** 읽고 동의하실 때만 USB를 만들어 직접 꽂아 주세요.

**동의 표시:** zip을 받아 USB에 넣으면 동의한 것으로 봅니다. 원치 않으면 `KP-AGREE.txt`를 지우세요. USB 맨 위에 이 파일이 없으면 USB를 꽂아도 **아무것도 기록하지 않고** 상태 화면에 "동의가 확인되지 않아 기록하지 않았습니다"만 남깁니다. 내비가 "실행할까요?" 창 없이 스크립트를 실행하는 때(부팅 직후 등)가 있어서, 창 대신 이 파일로 동의를 확인합니다. **`KP-AGREE.txt`가 있는 USB를 꽂아 두면 다음에 시동을 켤 때 묻지 않고 다시 기록하니, 기록을 마치면 USB를 빼 두세요.**

- **지나간 길과 목적지가 기록됩니다.** 순정 내비가 안내한 교차로 이름, 목적지 이름, 위치 값(지도 위 지점)과 그 시각입니다.
- 계기판에 보낸 안내 숫자(회전 그림 번호, 방향, 남은 거리, 차로)와 차 코드(예: `DEPEHEV.KOR.…`)도 기록됩니다.
- **차량 신호와 GPS도 기록됩니다.** 차속, 기어, 주차 브레이크, 야간 여부, GPS 방향·고도가 바뀔 때마다 적힙니다. 내비가 GPS를 다시 잡을 때마다 그때의 위치 값(위도·경도)도 적힙니다.
- **휴대폰 길안내를 켰다면** 카플레이·안드로이드 오토의 회전 번호·거리와 길안내 앱 이름(예: 지도 앱 이름)도 기록됩니다. 휴대폰 이름은 아닙니다.
- 그 밖에 제한속도·단속 안내 숫자, 터널·교량 여부, 화면 밝기 단계, 내비 시간대, Korea Projection·무선 모드 버전, 디버그 로그가 켜져 있는지가 기록됩니다.
- **기록하지 않는 것:** 휴대폰 이름, 블루투스 MAC, 차대번호(VIN), 비밀번호. 길안내·차량 신호 기록(`tbt.txt`)에는 정해진 줄만 골라 적고, 이런 값이 나오는 줄은 고르지 않습니다.
- **태그 요약(`tags.txt`):** 내비의 다른 로그는 로그를 남긴 프로그램 이름(태그)과 줄 수만 셉니다. **줄 내용은 적지 않습니다.** 태그 이름에서 한글 등은 `?`, MAC 꼴·전화번호 꼴·긴 숫자는 `#`로 가립니다. 영문으로 된 이름은 가리지 못하니, 보내기 전에 `tags.txt`를 한 번 열어 봐 주세요.
- 목적지·교차로 이름은 **내비에 보인 그대로** 적힙니다. 즐겨찾기 이름(예: 사람 이름)이나 장소 이름에 든 전화번호도 그대로 남으니, 원하지 않으면 그런 목적지로 기록하지 마세요.
- 결과는 USB에만 남습니다. 인터넷으로 보내지 않습니다.

**결과는 GitHub 이슈에 올리지 말고 메일로만 보내 주세요.** 받은 기록은 개발자의 비공개 폴더에만 두고 공개하지 않습니다. 보내기 전에 USB의 `KoreaProjection-private` 폴더를 직접 열어 보셔도 됩니다. 보내고 싶지 않으면 그 폴더를 지우면 됩니다.

## 내비에 하는 일

- 내비에서는 **읽기만** 합니다. 설정을 바꾸지 않고, 순정 앱을 다시 시작하지 않고, 계기판에 아무것도 보내지 않습니다.
- 내비 쪽에는 Korea Projection 상태 화면의 알림 한 줄만 씁니다. USB를 꽂으면 상태 화면을 한 번 엽니다.
- 기록하는 동안 내비가 눈에 띄게 느려지면 정차한 뒤 USB를 빼 주세요.
- Korea Projection이 설치된 차에서만 씁니다. **1.8.0 베타 3 이상**에서 써 주세요.

## 준비 (집에서)

- 이 폴더의 `korea-projection-tbtlog-usb.zip`을 받습니다. GitHub에서 그 파일 이름을 누른 뒤, 열린 화면 오른쪽의 내려받기 단추(아래 화살표, Download raw file)를 누릅니다. 파일 이름을 오른쪽 클릭해 "다른 이름으로 링크 저장"으로 받으면 안 됩니다.
- zip을 풀어 나온 `NEMESIS.data`(39바이트), `NEMESIS.sh`(약 42KB), `KP-AGREE.txt` 세 파일을 FAT32로 포맷한 USB 맨 위에 넣습니다. 32GB 이하 USB를 권합니다. exFAT·NTFS는 안 됩니다.
- 파일을 메모장 등으로 열어 다시 저장하지 마세요. 윈도에서 파일 이름 끝에 `.txt`가 붙지 않았는지 확인합니다(탐색기 "보기"에서 "파일 확장명"을 켜면 보입니다).
- 이 USB에는 다른 `NEMESIS.data`(설치용 등)가 없어야 합니다. `KP-AGREE.txt`의 이름은 바꾸지 마세요. 빈 공간은 100MB면 넉넉합니다.
- **디버그 로그를 켜야** 순정 회전 번호가 남습니다. 상태 화면 "고급"에서 켭니다. 무선 모드 설정의 계기판 안내(기본 켬)도 켜져 있어야 합니다. 켠 뒤 **재부팅**해 주세요(상태 화면의 재부팅, 또는 시동을 완전히 끄고 몇 분 뒤 다시 켬).
  - 이 기록 USB에는 휴대폰 이름이 들어가지 않습니다. 기록을 마친 뒤 디버그 로그는 다시 꺼도 됩니다.
- 순정 회전 번호는 내비가 한 번 켜질 때 약 2시간 30분 길안내 분량까지 남습니다(길에 따라 다릅니다). 출발 직전에 재부팅하면 처음부터 다시 셉니다.

## 차에서 (USB 한 번 꽂기)

1. **정차한 상태에서** 시동을 켭니다. 이번에는 카플레이·안드로이드 오토로 길안내를 켜지 말고 순정 내비만 씁니다.
2. **시동을 켜고 내비 화면이 다 뜬 뒤 2분 지나서 USB를 꽂으세요.** 실행할지 물으면 위 "기록되는 것"을 확인한 뒤 "예"를 누릅니다.
   - '실행할까요?' 창도 상태 화면도 1분 안에 안 뜨면 USB를 빼고 다시 꽂으세요. 부팅 직후에 꽂으면 창 없이 실행될 수 있어서입니다. 두 번 해도 안 뜨면 차종과 함께 알려 주세요.
3. 몇 초 뒤 상태 화면에 "길안내 기록을 시작했습니다(최대 180분). USB를 꽂아 둔 채 이 화면을 닫고 출발하세요."가 보이면 시작된 것입니다. 상태 화면을 닫습니다. "동의가 확인되지 않아 기록하지 않았습니다. …"가 보이면 USB를 빼서 PC에서 맨 위에 `KP-AGREE.txt`가 있는지 확인합니다(없으면 zip에서 다시 넣습니다). "시작하지 못했습니다"나 "확인하지 못했습니다"가 보이면 USB의 `KoreaProjection-private` 폴더를 보내 주세요.
4. **아직 정차한 채로** 순정 내비에서 목적지를 정하고 길안내를 시작합니다. 운전 중에는 내비를 조작하지 마세요.
5. USB를 꽂아 둔 채 달립니다. 기록은 **최대 180분**(3시간) 뒤 저절로 끝납니다.
6. 도착해서 정차한 뒤 USB를 뺍니다. 빼면 그때까지의 기록이 남습니다. **주행 중에는 USB를 빼지 마세요.** 기록을 마친 USB는 꽂아 두지 마세요(다음 시동 때 다시 기록할 수 있습니다).
7. 돌아오는 길도 기록하려면 2번부터 다시 합니다. 꽂을 때마다 새 폴더에 기록합니다.

- 지하차도·고가차도·갈림길·각도가 다른 교차로가 있는 길이면 더 도움이 됩니다.
- 동승자가 있으면 "몇 시쯤 지하차도" 같은 대략 시각만 메모해 주세요. **운전 중 촬영·조작은 하지 마세요.**
